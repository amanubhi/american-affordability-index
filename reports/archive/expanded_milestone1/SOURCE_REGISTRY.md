## Availability decisions

[Census schedule updated October 13](https://www.census.gov/programs-surveys/acs/news/data-releases/2025/release-schedule.html) lists October 29, 2026 for 2025 ACS 1-year tables. As of October 19, use 2024 as the **provisional common endpoint**, subject to ingestion checks. A 2025 metadata probe returned HTTP 404; do not interpret future-year availability from the project title.

[2020 experimental ACS FAQ](https://www.census.gov/programs-surveys/acs/data/experimental-data/faq.html) advises against comparisons to standard estimates. Leave 2020 annual income/rent comparisons missing; do not interpolate or substitute overlapping five-year estimates. Price-only charts may retain 2020.

[Census June 2026 guidance](https://content.govdelivery.com/accounts/USCENSUS/bulletins/41aaf23) confirms a key is required for data queries, but not metadata. Store a future key as CENSUS_API_KEY locally or in CI secrets; never commit it. This is an access dependency for Milestone 2, not evidence of bad data. No key signup or account actions were performed.

## Evidence and remaining verification

`data/reference/feasibility/retrieval_manifest.json` contains probe URLs, return codes and hashes. `reports/source_feasibility_metrics.json` records offline checks and fingerprints. HTTP success alone is insufficient: Census returned an HTML key page with status 200. Ingestion must validate content type, JSON structure, API status and expected keys.

BLS only 2015–2024 was probed here. EIA monthly table has history before 2015, but only the proposed project period was audited. ACS intermediate-year definitions, all 50 state/DC observations, missing/sentinel rates, uncertainty, year-to-year consistency and full endpoint intersections remain unverified. This milestone establishes a feasible design, not a certified integrated panel.
